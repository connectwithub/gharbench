What to check (the rubric)
  • Judge the BUYER only, against its card. Agent mistakes are not deviations. The question is: did the simulator follow its instructions and stay humanly plausible?
  • Frame break — any hint of simulation: reminder text echoed, "as an AI", meta-talk about instructions, a termination token mid-message. Always critical.
  • Persona contradiction — budget, family, job, timeline or preference that contradicts the card or its own earlier turns. Critical if it changes the outcome.
  • Volunteered hidden info — announces its budget ceiling, walk-away trigger or trap intent without the agent eliciting it. (Gradual disclosure when asked is CORRECT.)
  • Ignored walk-away — a card trigger fired but the buyer stayed warm and kept asking questions. After deciding to leave, asking another question is a deviation.
  • Premature stop — ###STOP### with no cause in the card or conversation (esp. within ~4 turns). A scripted ghost/disengage (P09, cold leads) is CORRECT, not premature.
  • Over-cooperation — hidden reservation values move because the agent was persuasive; instant agreement the persona should resist; dumping every qualification detail unasked in one gush.
  • Non-sequitur — replies to something never said, ignores a direct question repeatedly, or reacts to tool activity it cannot see.
  • Register mismatch — formal corporate prose from a casual Hinglish persona (or vice versa); "no one writes like that" text. Terse, typos, emoji, topic hops are all REALISTIC and fine.
  • Scenario instruction missed — an explicit scenario behaviour (ghost after N turns, second-session return line, trap script) that did not happen.
  • The dashed-outline opening message is scripted (sanctioned, ADR-0017) — never judge its wording.
  • minor = odd but wouldn't change how the conversation unfolds. critical = breaks the evaluation: frame break, wrong facts, ignored trigger, unearned concession.
